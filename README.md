# 🎓 Técnico em Informática para Internet -- FAT

Este repositório reúne os **materiais, páginas e disciplinas organizadas
por semestre** do curso **Técnico em Informática para Internet -- FAT**,
com foco em estudos práticos de **HTML, CSS e JavaScript**.

O projeto foi desenvolvido com o objetivo de **praticar desenvolvimento
web**, organização de conteúdo educacional e construção de um layout
responsivo e acessível.

------------------------------------------------------------------------

## 📚 Estrutura do Projeto

-   **Primeiro Semestre**
    -   Análise de Requisitos

    -   Produção de Textos
-   **Segundo Semestre**

    -   (em desenvolvimento)
