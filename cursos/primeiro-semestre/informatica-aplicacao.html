Aula 09 - Linguagens de programação

Um breve panorama da história das linguagens de programação

A história das linguagens de programação acompanha a própria evolução da tecnologia e das máquinas inteligentes. Desde o início, o objetivo sempre foi transformar sequências lógicas em soluções para problemas reais.

Um dos primeiros marcos dessa trajetória foi o tear automatizado criado por Joseph-Marie Jacquard, capaz de executar padrões sem a intervenção humana. Essa invenção inspirou Ada Lovelace, que desenvolveu os primeiros algoritmos para o computador idealizado por Charles Babbage, sendo considerada a primeira programadora da história. A partir daí, nasceu o conceito de linguagem de programação.

Com o avanço da tecnologia, percebeu-se a necessidade de diferentes linguagens para diferentes tipos de problemas e aplicações. Hoje, as linguagens de programação costumam ser classificadas conforme o tipo de aplicação que atendem:

  • 🖥️ Desktop: programas instalados no computador, como editores de texto e planilhas (Word, Excel, entre outros).
  • 🌐Web: aplicações acessadas pela internet, como sites, sistemas online e calculadoras web.
  • 📲Mobile: aplicativos para smartphones, disponíveis em lojas como App Store e Play Store.

📚Linguagens mais usadas atualmente

Entre as linguagens mais populares no mercado, destacam-se:

  • Java – conhecida pela segurança, rapidez e confiabilidade. Seus programas são executados por meio de uma máquina virtual, o que garante portabilidade entre diferentes sistemas.
  • JavaScript – amplamente utilizada no desenvolvimento web, é responsável pelas interações visuais e dinâmicas que dão vida às aplicações.
  • Python – famosa pela simplicidade e legibilidade, favorece a produtividade e a manutenção do código.
  • SQL – utilizada para manipulação e gerenciamento de bancos de dados de forma eficiente.

Além dessas, a linguagem C é muito comum no ambiente acadêmico, pois ajuda no aprendizado da lógica de programação e deu origem a várias outras linguagens, como C++ e C#. Sua simplicidade e proximidade com o funcionamento do computador fazem dela uma excelente base para iniciantes.
